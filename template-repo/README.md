# Repository Template: DanDeBugger-enabled

This repository is a template that includes the `DanDeBugger` persona instructions and basic repository scaffolding.

When you create a new repository from this template (GitHub: Use this template), the new repo will include the `docs/DanDeBugger.md` file so your projects consistently carry the developer/AI guidance.

Contents worth noting:
- `docs/DanDeBugger.md` — the DanDeBugger persona prompt and usage guidance.
- `.gitignore` — a minimal starter `.gitignore`.
- `CONTRIBUTING.md` — short onboarding notes.

How to use
1. Push this folder to a new GitHub repository under your account (e.g., `dan-de-bugger-template`).
2. On GitHub, go to the repo Settings -> Template repository -> Enable. The repo becomes available as a template.
3. When creating a new repo on GitHub, choose "Use this template" and select this repository.

Optional automation: pair this template with the automation scripts in the parent workspace to ensure existing repos get a copy as well.
