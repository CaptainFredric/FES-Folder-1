# Contributing

This is a simple template repository. If you create a new repository from this template, consider:

- Replacing this `CONTRIBUTING.md` with your project's contribution guidelines.
- Reviewing `docs/DanDeBugger.md` and adjusting the instructions for the specific project.

If you want the DanDeBugger persona to be enforced or checked automatically, pair this template with the automation scripts in the parent workspace or add a GitHub Action to propose a PR when the file is missing.
